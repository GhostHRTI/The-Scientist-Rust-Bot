Providers

GPortal and Nitrado

The Scientist should document provider support honestly. Rust Console providers do not always expose public APIs for every desired server-management action. The bot must separate confirmed integration paths from manual-owner workflows.

Supported Design Pattern

  • Provider profile storage with encrypted secrets where supported.
  • Manual setup fallback when direct API access is unavailable.
  • Audit logs for every provider-related action.
  • No fake endpoints, mock “working” APIs, or hardcoded provider responses.

Integration Modes

ModeDescription
ManualThe bot gives guided instructions and tracks completion status.
Semi-automatedThe bot stores configuration and generates provider-ready steps.
API-backedUsed only where a legitimate, documented provider API supports the operation.
