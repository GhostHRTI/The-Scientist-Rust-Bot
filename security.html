Security

Security Model

Principles

  • Never commit tokens, provider credentials, database URLs, or Redis URLs.
  • Use least-privilege Discord permissions.
  • Store secrets in environment variables or a secrets manager.
  • Log sensitive actions without exposing private values.
  • Rate-limit high-risk commands and provider workflows.

Permissions

Owner-only actions should be separate from administrator actions. Economy mutation, kit editing, provider configuration, and destructive reset commands should require explicit role or owner checks.

Audit Events

Every high-impact action should write an immutable audit entry: who triggered it, what changed, where it happened, and when it occurred.
