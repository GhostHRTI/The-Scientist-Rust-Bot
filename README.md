# The Scientist GitHub Pages Site

This folder contains a static GitHub Pages documentation site for **The Scientist**, a professional Rust Console Edition Discord bot.

## Pages included

- `index.html` — public landing page
- `docs/index.html` — documentation homepage
- `docs/setup.html` — setup guide
- `docs/commands.html` — command matrix
- `docs/modules.html` — feature/module docs
- `docs/providers.html` — GPortal/Nitrado integration boundaries
- `docs/security.html` — security model
- `docs/deployment.html` — deployment guide
- `docs/roadmap.html` — development roadmap
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow
