Setup

Server signal acquired.

Requirements

LayerRecommended
RuntimeNode.js 20 LTS or newer
DiscordDiscord.js v14 with slash commands
DatabasePostgreSQL with Prisma migrations
CacheRedis for cooldowns, queues, and temporary state
ProcessDocker Compose or PM2

Environment

DISCORD_TOKEN=
DISCORD_CLIENT_ID=
DATABASE_URL=postgresql://user:password@localhost:5432/the_scientist
REDIS_URL=redis://localhost:6379
BOT_OWNER_IDS=123456789012345678
NODE_ENV=production

Install

npm install
npx prisma migrate deploy
npm run build
npm run start

First Discord Setup

  1. Invite the bot with application command permissions.
  2. Run /scientist setup in the owner Discord server.
  3. Select region, platform, provider, feed channels, economy defaults, and staff roles.
  4. Run a final audit using /scientist audit.
