Deployment Guide

Docker Compose

PM2

npm ci
npm run build
npx prisma migrate deploy
pm2 start dist/index.js --name the-scientist
pm2 save

Production Checklist

  • Enable backups for PostgreSQL.
  • Use Redis persistence only where needed.
  • Set restart policy for the bot process.
  • Configure alert channel for crashes and failed provider jobs.
  • Run a permissions audit before public launch.
