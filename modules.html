Modules

Core Systems

Setup Wizard

Guided server onboarding for permissions, channel routing, provider mode, feed toggles, and default economy values.

Player Linking

Links Discord users to Xbox or PlayStation identities for role rewards, stats, and controlled economy actions.

Economy + Shop

Persistent wallets, shop listings, purchase history, rewards, cooldowns, price controls, and server-specific settings.

Kits

Advanced kit builder with item presets, claim cooldowns, role locks, wipe resets, and logging.

Feeds

Routes configured events into Discord channels. Examples: server status, wipe reminders, economy logs, kit claims, admin actions, and provider notes.

Automation

Scheduled reminders, wipe workflows, recurring messages, economy resets, role sync, and server health checks.

Statistics + Leaderboards

Profiles, linked accounts, economy ranking, activity metrics, event records, and historical summaries.
